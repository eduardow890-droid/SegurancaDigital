# Segurança Digital

Site educativo de segurança da informação e proteção de dados (HTML, CSS e JavaScript puros).

## Como abrir
- Abra `index.html` no navegador, ou use a extensão Live Server no VS Code.
- As fontes vêm do Google Fonts; sem internet, o site usa fontes do sistema.

## Estrutura
- `index.html`: estrutura e conteúdo
- `css/style.css`: identidade visual (tema claro e escuro)
- `js/app.js`: simulações, quiz, diagnóstico e progresso (salvo no navegador)
- `img/`: imagens (WebP e SVG)
